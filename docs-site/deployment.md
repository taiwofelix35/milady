# Documentation Deployment

This folder is an external docs bundle intended for separate hosting at docs.miladyontempo.xyz.

## Recommended Publish Target

- Domain: docs.miladyontempo.xyz
- Publish mode: static markdown or markdown-to-site generator

## Bundle Contents

- index.md
- mint.md
- roadmap.md
- deployment.md
- navigation.json

## Release Process

1. Update docs so product offering and usage steps are clear.
2. Confirm mint values and schedule are current.
3. Confirm rebrand messaging is up to date.
4. Publish docs bundle to hosting provider.
5. Verify public navigation and deep links.
6. Announce docs update in project channels.

## Pre-Publish Checklist

- Mint supply is 1,111 in docs and launch config.
- Mint price is 3 MILADY in docs and launch config.
- Mint date and time are current and approved.
- Rebrand note is aligned with current launch timeline.

## Post-Publish Validation

1. Open docs root and all section links.
2. Validate roadmap dates and mint date.
3. Validate rebrand section wording and timing.
4. Confirm mobile rendering quality.

## Rollback Strategy

- Keep previous docs bundle version as an artifact.
- If incorrect content is published, revert to prior bundle and republish corrected version.
